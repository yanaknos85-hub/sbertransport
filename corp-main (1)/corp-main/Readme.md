# Corp frontend microservices "Main"

## Устанавливаем версию ноды

`nvm use`

___

## Устанаваливаем пакеты строго по yarn.lock

`yarn ci`

или:

`yarn install --frozen-lockfile`

___

## Запуск приложения (Пример!)

`yarn start:dev-cargo` запуск микрофронта c Судир авторизацией

`yarn start-auth:dev-cargo` запуск микрофронта c Basic авторизацией
