## 6. Критерии приёмки EPIC (AC)

1. Существует карточка с основными ID, статусом, ролью Банка, титулами
2. Цепочка Т1–Т4, у каждого — статус, источник, подписант, документ, ошибка
3. Различие bank_is_sender / receiver / initiator
4. required_bank_titles определяет титулы для очереди
5. routeContext — внешний контекст, не маршрут
6. Модель пакета /cs/title3: batch + item
7. Базовая модель PDF
8. Очередь: только готовые титулы Банка
9. Lock: один подписант, запрет параллельной подписи
10. Механизм возврата в очередь
11. Карточка из очереди: цепочка, роль, routeContext, PDF, статусы, ошибки, история
12. Читаемая причина блокировки
13. RBAC: просмотр, подпись, поддержка, администратор, аудит
14. Журнал событий: дата, источник, пользователь/система, результат
15. Feature flags для этапов
16. Данные EPIC-00 используются EPIC-01, EPIC-06 без дублирования
