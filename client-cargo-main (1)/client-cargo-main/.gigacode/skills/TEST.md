# Тестирование

## Общие принципы

- Используйте **Jest** как тестовый движок
- Используйте **React Testing Library** для компонентов
- Тесты пишите на русском языке
- Используйте `describe` для группировки тестов по сценариям
- Используйте `test` для отдельных тестов
- Тестируйте поведение функции, а не реализацию

# Задача

Написать тесты с использованием Jest и React Testing Library.

## Цель

Достичь максимального покрытия строчек кода (statements, branches, functions, lines).


## Задачи / Шаги

1. Прочитать файл @sonar-project.properties и обратить внимание на исколючения (sonar.cpd.exclusions и sonar.coverage.exclusions) - эти файлы и директории не трогать!
3. Провести анализ оставшегося кода, исходя из пукта 1 (Не использовать lint!)
4. Вывести спискок файлов для потенциального изменения в формате: путь до файла - % текущего покрытия
5. Отдельном пунктом вывести файлы которые совсем без тестов
6. Спросить разрешение на редактирование и только после этого приступать

## Требования к тестам:

Тест-кейсы на русском языке без номера теста. Тесты которые долго не получается реализовать - игнорировать или удалять

## Что нужно тестировать:

Условный рендеринг (ветвления, тернарные операторы)
Логику в useEffect и его зависимости
Вызов callback-функций (например, onChange, redirectByAddress)
Взаимодействие с хуками (useUrl, useParams и т.д.)
Корректную передачу пропсов дочерним компонентам
Обработку различных состояний/параметров

## Что НЕ нужно тестировать:

Наличие статичных элементов, которые рендерятся всегда
CSS-стили, классы, атрибуты, не влияющие на логику
Пропсы UI-кита (например, gap, vertical, tabBarGutter)
Количество вызовов функций без привязки к ветвлениям
То, что очевидно из самого рендера (например, что компонент отрендерился без ошибок)

## Принцип:

Каждый тест-кейс должен проверять конкретную логическую ветку или сценарий, который может быть не выполнен при другом наборе входных данных. Если проверка будет успешна при любом рендере компонента — она избыточна.

Используй моки для внешних зависимостей (хуки, дочерние компоненты).
